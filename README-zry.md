# Lab3
源码说明：
- kernel/vm.c:
    - kvm开头的函数：操作内核页表
    - uvm开头的函数：操作用户页表
    - 其他：两者通用
    - 核心函数：
        1. `walk`: 为虚拟地址找PTE
        2. `mappages`: 为新映射装载PTE 
        3. `copyout`：复制数据到用户虚拟地址，虚拟地址为参数
        4. `copyin`：从用户虚拟地址复制数据，虚拟地址为参数
        5. `kvmmap`：内核建立映射


## 物理内存分配
- `kalloc.c`：分配器的数据结构式可供分配的物理内存页的空闲链表
- `struct run`：空闲页列表元素
